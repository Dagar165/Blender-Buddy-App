# JKids Bot — приложение-тамагочи для учеников школы 3D

Telegram-мини-приложение школы JKids. У подростка живёт призрак-питомец,
который растёт от того, что ребёнок реально сделал в Blender: каждый день —
задание, каждую неделю — проект из пяти шагов, каждый шаг проверяет живой
куратор руками.

**Живое приложение:** https://dagar165.github.io/Blender-Buddy-App/

---

## Как запустить у себя

Нужен Node 20 или новее.

```bash
npm install
```

```bash
npm run dev
```

Откроется на `http://localhost:5173/Blender-Buddy-App/`.
Обрати внимание на хвост адреса: приложение живёт **не в корне сайта**,
и это важно для ссылок на картинки (см. ниже).

Перед любой выкладкой:

```bash
npm run check && npm run build
```

`check` — это `tsc`, ловит опечатки за секунды. `build` — сборка.

---

## Как правки попадают на сайт

Только через `push` в ветку `main`. Дальше GitHub Actions сам собирает
и публикует. **Сохранить файл недостаточно** — пока нет пуша, на сайте
ничего не изменилось.

Телеграм кэширует старую версию до десяти минут. Если кажется, что правка
не приехала, — сначала убедись, что смотришь новую сборку.

## Что где лежит

| папка | что внутри |
|---|---|
| `client/src/pages/` | четыре экрана: питомец, задания, магазин, профиль |
| `client/src/components/` | куски экранов и полноэкранные окна |
| `client/src/lib/` | **настройки и тексты** — почти всё, что хочется поменять словами |
| `client/src/game/` | механики без разметки: уровни, серия, даты, гардероб, облако |
| `client/src/hooks/use-game-state.ts` | стор: всё, что приложение помнит про ученика |
| `client/src/components/ui/` | готовые кирпичи от библиотеки, их не трогаем |
| `client/public/` | файлы как есть: картинки зала славы, лендинг марафона |
| `worker/` | серверок на Cloudflare: заявки куратору и их статусы |
| `tools/` | разовые скрипты для картинок (вырезание, сжатие в webp) |

У каждого файла в `lib/` есть шапка с правилами правки. **Начни с неё,
а не с кода.**

| кривую опыта до 30 уровня | `game/level.ts` |
| тексты приветствия при первом входе | `lib/welcome-config.ts` |

## Правила, которые нельзя нарушать

Каждое куплено ошибкой на живых пользователях. Подробный разбор — в файле
`JKids_Bot_как_работать_25.07.md` (лежит у владельца на рабочем столе,
в папке `Бот-тамагочик`).

1. **Награду за задание даёт только куратор.** Нажатие «Выполнил» лишь
   отправляет заявку. Опыт и голда начисляются, когда пришёл ответ
   «подтверждено». Начислить раньше — выдать награду за непроверенную работу.
2. **Пока шаг проекта не подтверждён, следующий не открывается.** Всегда,
   все семь дней. Это пробовали отменить и вернули обратно.
3. **Призрак не уменьшается.** Ни от длины реплики, ни от высоты телефона.
   Нужно место на экране — убирай другие блоки, а не его.
4. **У призрака два верха:** верх картинки и верх одежды. Холст одежды выше
   на 18% — шляпа торчит примерно на 43 точки над картинкой. Проверяя
   наезды сверху, мерить надо по одежде.
5. **Экраны главной обязаны помещаться в окно.** Никаких блоков,
   раскрывающихся в высоту — они ломают переключение свайпом. Длинный
   список — только отдельным окном через `createPortal`.
6. **Никаких анимаций и наблюдателей там, где важно состояние.**
   Есть места, где браузер не выдаёт кадры: CSS-переходы и
   `IntersectionObserver` там застревают навсегда. Полноэкранные окна
   делаются БЕЗ анимаций появления.
7. **Отступ под нижние вкладки отведён один раз в `App.tsx`** (`pb-[80px]`).
   Внутри экранов его добавлять не надо — посчитается дважды.
8. **Путь к картинкам из `public/` строится через `import.meta.env.BASE_URL`.**
   Приложение живёт не в корне сайта; ссылка со слэша уйдёт мимо.
9. **В зале славы только ники в Телеграме.** Имён детей нет и быть не может —
   на имя нужно согласие родителей.
10. **Проверять вёрстку на окне 393×700** и мерить высоту в консоли,
    а не оценивать на глаз.

## Как проверить, что ничего не сломал

1. `npm run check` — типы.
2. `npm run build` — сборка.
3. `npm run dev` и окно 393×700 — посмотреть глазами.
4. Всё, что зависит от Телеграма (аватарка, вибро, данные запуска, жесты),
   проверяется **только на живом сайте** — в обычном браузере этого нет.

Перед крупной правкой поставь метку для отката:

```bash
git tag tochka-otkata-ггммдд && git push origin tochka-otkata-ггммдд
```
